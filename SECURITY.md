# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through GitHub's
[private vulnerability reporting](https://github.com/sunilkayz007/AIMeals/security/advisories/new).

Include a description of the issue, steps to reproduce, and the affected version or commit.
You can expect an initial response within a few days.

## Scope

In scope: the backend API in `backend/` and the mobile app in `mobile/`.
Out of scope: third-party services (Google Play, RevenueCat, AI providers) and issues that require a rooted or compromised device.
