# Contributing to AIMeals

Thanks for your interest in AIMeals. Bug reports, feature ideas and pull requests are welcome.

## Reporting bugs and requesting features

Open an issue using the bug or feature template. Include steps to reproduce, the app version, and your device or Android version for mobile bugs.

## Development setup

See the **Running locally** section of the [README](README.md) for the backend and mobile setup.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep changes focused. One fix or feature per pull request.
3. Make sure the backend starts and the mobile app builds before opening the PR.
4. Fill in the pull request template.

## Code and secrets

- Never commit `.env` files, keystores, signing keys, `google-services.json` or any API key. Use the `.env.example` files as templates.
- Follow the style of the surrounding code.
